# Personal Developer Portfolio

A modern, responsive, and interactive developer portfolio built to showcase my technical skills, projects, experience, and journey in software development.

**Live Portfolio:** https://portfolio-cyan-zeta-28.vercel.app/

---

## About the Project

This portfolio is designed to provide a central place to showcase my development work, technical expertise, and professional journey.

The project focuses on creating a clean, responsive, and user-friendly experience while following modern frontend development practices.

It also serves as a practical demonstration of my experience with React.js, JavaScript, responsive UI development, version control, and deployment workflows.

---

## Features

* Modern and responsive user interface
* Fully responsive across different screen sizes
* Fast development and optimized build with Vite
* Component-based architecture using React
* Dedicated sections for projects and skills
* Developer-focused personal introduction

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
